Hế lô các bạn với các bé!

Như đã hứa thì nay mình sẽ share cho mọi người một số trang web khá là hay để rèn luyện kỹ năng code Front-end web, sử dụng framework Tailwind CSS. Các trang mình lượm lặt được là:
# **1. Lineone**: https://lineone.piniastudio.com/

Trang này có rất nhiều mẫu thiết kế cho các loại web khác nhau. Mỗi thiết kế của nó đều rất là xịn nên các bạn muốn sau này làm designer web cũng có thể xem để lấy ý tưởng về các UI/UX.

Còn bạn nào muốn code ra những trang đẹp đẽ như dị thì có thể F12 để xem source code, cách họ xài những class Tailwind để style cái trang web như thế nào.

Ở mấy cái tab dưới cùng, mọi người click vô sẽ thấy những mẫu thiết kế cho các components thường dùng, ví dụ như form, tab, timeline... Nói túm lại là mọi người cứ click vô tất cả những thứ-có-thể-click được trên trang web để khai thác tối đa giá trị của cái web này nhớ=))

# **2. Tailwind Playground: https://play.tailwindcss.com/**

Trang này thì nó đơn giản là một cái playground để các bạn tập làm quen với Tailwind à. Riêng mình thấy nếu mới làm quen Tailwind, học được cái gì đó lạ lạ muốn áp dụng thử coi nó ra làm sao thì lên trên đây thử liền là tuyệt vời=)) Đỡ phải mất công tạo mới project trong máy rồi set up các kiểu cũng khá tốn thời gian=)) Nhưng mà nếu muốn xài trong các dự án cá nhân thì bắt buộc phải biết cách set up từ đầu nhá. Mấy này trên mạng người ta hướng dẫn cũng nhiều, chịu khó tra cứu xíu là ra à:333

Xong rùi. Chúc các bạn theo sự nghiệp FE web hoặc designer web sẽ học được nhiều thứ từ những trang này. Mọi người có gì hay muốn chia sẻ thì cứ mạnh dạn post bài nhá🥳🥳🥳
