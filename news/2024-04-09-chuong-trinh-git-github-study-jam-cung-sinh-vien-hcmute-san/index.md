🧑‍💻 Chương trình Git  Github Study Jam cùng sinh viên HCMUTE Sân chơi giúp các bạn sinh viên Khoa CNTT làm quen với Git và GitHub, rèn luyện kỹ năng làm việc nhóm trong quy trình phát triển phần mềm theo hướng chuyên nghiệp. Chương trình thu hút gần 40 bạn đăng ký tham dự, được chia làm 10 đội thi với đề bài xây dựng một website hay phần mềm sử dụng Git  GitHub quản lý mã nguồn. Sau 3 tuần thi căng thẳng cùng những nhiệm vụ khác nhau, BTC đã tìm ra 3 đội xuất sắc nhận những giải thưởng và phần quà vô cùng hấp dẫn đến từ KMS Healthcare.  
✨ Chúc các bạn sinh viên luôn tích cực nâng cao các kỹ năng cần thiết để có thể tự tin tham gia vào môi trường làm việc thực tế nhé! —- 𝐆𝐢𝐭  𝐆𝐢𝐭𝐡𝐮𝐛 𝐒𝐭𝐮𝐝𝐲 𝐉𝐚𝐦 𝐰𝐢𝐭𝐡 𝐇𝐂𝐌𝐔𝐓𝐄 𝐒𝐭𝐮𝐝𝐞𝐧𝐭𝐬 The program provides a platform for students from the Faculty of Information Technology, HCMC University of Technology and Education, to familiarize themselves with Git and GitHub, as well as develop their teamwork skills in a professional software development process.
