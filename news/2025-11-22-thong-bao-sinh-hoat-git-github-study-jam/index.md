\# **\[THÔNG BÁO SINH HOẠT GIT  GITHUB STUDY JAM\]** Buổi sinh hoạt đầu tiên sẽ là điểm khởi động nhẹ nhàng để mọi người làm quen và chuẩn bị cho hành trình học – thực hành trong những tuần tới. ## 🔰 Nội dung buổi sinh hoạt đầu tiên Trong buổi này, BTC sẽ cùng các bạn:  
🔹 **Giới thiệu tổng quan chương trình** — Thời gian, cách tính điểm, quyền lợi, yêu cầu nhiệm vụ từng tuần.

<!--truncate-->

🔹 **Tạo nhóm  ổn định đội hình** — Với những bạn đã có nhóm: xác nhận lại thành viên. — Với những bạn chưa có nhóm: BTC sẽ hỗ trợ ghép nhóm ngay tại buổi sinh hoạt.  
🔹 **Làm quen với Git  GitHub** — Giải thích các khái niệm cơ bản (repository, commit, branch…). — Hướng dẫn tạo GitHub repo nhóm. — Hướng dẫn cài đặt Git và thiết lập môi trường làm việc trên máy. — Demo thao tác đầu tiên: \*clone – commit – push*. Buổi đầu chỉ mang tính mở màn, siêu nhẹ nhàng để các bạn nắm được hướng đi, làm quen với cộng đồng và chuẩn bị cho thử thách thú vị những tuần sau.
